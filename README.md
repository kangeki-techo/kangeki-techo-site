# 観劇手帖

観劇日程から公演を探し、劇場ごとの座席レビューを確認・投稿できるサイトです。

## 主なページ

- `index.html`: 公演検索
- `reviews.html`: 劇場一覧
- `theater.html`: 劇場詳細・座席レビュー
- `post.html`: レビュー投稿
- `contact.html`: お問い合わせ
- `privacy.html`: プライバシーポリシー
- `rules.html`: レビュー投稿ルール

## データ管理

公演情報、劇場情報、座席レビュー、お問い合わせは Google スプレッドシートと Apps Script API で管理します。

## 現在の状態

元レイアウトをベースに、赤系カラーへ調整した試作版です。
公開前に、掲載する公演情報・劇場情報・文言・デザインを確認してから本公開します。
